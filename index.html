01 / History

The Birth of JavaScript

Created in 10 days. Ran the internet for 30 years.

1995

Brendan Eich Creates JS

Netscape hired Brendan Eich to create a scripting language for browsers. He wrote the first version in just 10 days. It was originally called Mocha, then LiveScript, then finally JavaScript.

1997

ECMAScript Standard Born

JavaScript was submitted to ECMA International for standardization. The result was ECMAScript 1 — a specification that all browsers agreed to follow.

2008

V8 Engine & Speed Revolution

Google released the V8 JavaScript engine with Chrome. V8 compiled JS directly to machine code using JIT compilation, making it blazing fast.

2009

Node.js — JS Leaves the Browser

Ryan Dahl used V8 to create Node.js, allowing JavaScript to run on servers. JS became a full-stack language.

2015

ES6 — The Modern Era

ECMAScript 2015 (ES6) was the biggest update ever: let, const, arrow functions, classes, promises, template literals, and destructuring — the JS we write today.

Copy by Value vs Copy by Reference

When you assign a variable to another, the behavior depends entirely on its type. Primitives are copied completely (by value), while Non-Primitives share the same memory address (by reference).

🔷 Primitive: Copy by Value

Changing the copy does not affect the original.

let a = 10; let b = a; // b gets a fresh copy of 10 b = 20; // only b changes console.log(a); // 10 console.log(b); // 20

🔶 Non-Primitive: Copy by Reference

Both variables point to the same underlying object.

let obj1 = { name: "Alice" }; let obj2 = obj1; // obj2 points to obj1's memory obj2.name = "Bob"; // modifies shared object console.log(obj1.name); // "Bob" 🤯 console.log(obj2.name); // "Bob"

06 / Quirks & Built-ins

JavaScript Surprises

JS has some unique behaviors that often surprise newcomers.

⬇️

Math.floor()

Always rounds down to the nearest integer — even for negatives.

🦄

typeof null === "object"

A famous bug from 1995 that was never fixed for backwards compatibility.

typeof null; // "object" 🤯
typeof function(){}; // "function"
typeof []; // "object"
🔢

== vs ===

Double equals coerces types. Triple equals is strict — no coercion.

0 ==  ""  // true 😱
0 === ""  // false ✅
null == undefined // true
🔤

String Coercion

The + operator converts numbers to strings when mixed with strings.

"5" + 3   // "53" (concat)
"5" - 3   // 2 (math)
1 + 2 + "3" // "33"
📶

Hoisting

var declarations and function declarations are "hoisted" to the top of their scope.

sayHi(); // Works! ✅
function sayHi() { /* ... */ }

sayBye(); // TypeError ❌
const sayBye = () => {};
⚡

Single Threaded

JS runs on one thread but uses the Event Loop for non-blocking async operations.
