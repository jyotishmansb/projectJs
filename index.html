01 / History

The Birth of JavaScript

Created in 10 days. Made for Noob coders

1995

Brendan Eich Creates JS

Netscape hired Brendan Eich to create a scripting language for browsers. He wrote the first version in just 10 days.
It was made for noob coders,it was made beginner-friendly.
First JavaScript engine that executed JavaScript code was implemented largely in C/C++
Your JavaScript Code → JavaScript Engine (a C++ program) → Machine Code
let x = 10 + 20;
console.log(x);
The JavaScript engine (a C++ program) reads this code, processes it, and executes it.
So when people say: "JavaScript runs in the browser" what's actually happening is: "A JavaScript engine written mostly in C++ is running your JavaScript code."

1997

ECMAScript Standard Born

JavaScript was submitted to ECMA International for standardization. The result was ECMAScript 1 — a specification that all browsers agreed to follow.

2008

V8 Engine & Speed Revolution

Google released the V8 JavaScript engine with Chrome. V8 compiled JS directly to machine code using JIT compilation, making it blazing fast.

2009

Node.js — JS Leaves the Browser

Ryan Dahl used V8 to create Node.js, allowing JavaScript to run on servers. JS became a full-stack language.

2015

ES6 — The Modern Era

ECMAScript 2015 (ES6) was the biggest update ever: let, const, arrow functions, classes, promises, template literals, and destructuring — the JS we write today.

Copy by Value vs Copy by Reference

When you assign a variable to another, the behavior depends entirely on its type.
Primitives are copied completely (by value), while Non-Primitives share the same memory address (by reference).

🔷 Primitive:
Copy by Value

Changing the copy does not affect the original.

let a = 10;
let b = a; // b gets a fresh copy of 10
b = 20; // only b changes console.log(a); // 10 console.log(b); // 20

🔶 Non-Primitive:
Copy by Reference

Both variables point to the same underlying object.

let obj1 = { name: "Alice" }; let obj2 = obj1; // obj2 points to obj1's memory
obj2.name = "Bob"; // modifies shared object console.log(obj1.name); // "Bob" console.log(obj2.name); // "Bob"

05 / Functions

Functions are Data type in JS

In JS, functions are objects- They can be stored in variables, passed to other functions, and returned from functions just like any other value.

You can store a function in a variable

// Now you can use the variable to run the function
